# KIKIAME - Comércio Geral e Prestação de Serviço

Website institucional desenvolvido para a empresa KIKIAME Comércio Geral e Prestação de Serviço, Lda.

## Funcionalidades

- Página inicial moderna
- Design totalmente responsivo
- Menu Mobile
- Animações com AOS
- Contadores animados
- Secção Sobre
- Serviços
- Projetos
- Parceiros
- Modal de Orçamento
- Modal Fale Connosco
- Integração com WhatsApp
- Google Maps
- Botão Voltar ao Topo

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts
- AOS (Animate On Scroll)

## Como executar

1. Faça o download do projeto.
2. Abra a pasta no Visual Studio Code.
3. Instale a extensão **Live Server**.
4. Clique com o botão direito em `index.html`.
5. Selecione **Open with Live Server**.
